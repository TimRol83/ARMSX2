# SYNAPSE HANDOFF — ПРОЕКТЫ АРХИТЕКТОРА (iPhone 6s / iOS 15)

## 0. ПРАВИЛА ВЗАИМОДЕЙСТВИЯ
- **Роли:** Пользователь — **Архитектор** (руки, сборка, тестирование на железе). Ассистент — **Синапс** (глаза, мозги, диагностика логов, генерация готовых Python/Bash-патчей для терминала).
- **Стиль:** Чётко, технически точно, без воды и догадок «наугад». Перед стартом любого нового проекта — обязательный нулевой аудит на совместимость с **Apple A9 (ARMv8.0-A)** (отсутствие LSE-атомиков ARMv8.1+, лимит ОЗУ, живость репозитория).

## 1. ЦЕЛЕВОЕ ЖЕЛЕЗО И ОКРУЖЕНИЕ
- **Устройство:** iPhone 6s (чип **Apple A9**, 2 ядра Twister, ARMv8.0-A, GPU PowerVR GT7600, 36-битная шина виртуальных адресов).
- **ОС и права:** iOS 15 + **Dopamine** + **TrollStore**.
- **Критические преимущества среды:**
  - **JIT доступен всегда и всем процессам** на уровне ядра.
  - **Memory+ / Extended Memory:** лимит ОЗУ на процесс расширен до **1.3–1.4 ГБ** (вместо стандартных ~1.1 ГБ).
- **Машина разработки:** MacBook Pro (репозитории на `~/Desktop/Madeira-A9` и `~/Desktop/ARMSX2-master`), сборка `.ipa` идёт через **GitHub Actions** (один раннер macOS 26 в очереди).

## 2. ПРОЕКТ №1: Madeira-A9 (`~/Desktop/Madeira-A9`, репо `TimRol83/Madeira-TrollStore`)
- **Цель:** Запуск старых 32-битных Windows XP игр (2004–2013 гг.) с аппаратным ускорением D3D9 → DXMT → Metal и JIT.
- **Приоритетные игры:** *Mark of the Ninja*, *Limbo*, *Braid* (в перспективе фикс тач-управления в *Knytt Stories*).
- **Что уже сделано:**
  1. Интегрированы **Mono 2.0** и **D3D9 (DXMT)** для iOS 15.
  2. Переписана карта виртуальной памяти FEX/Wine (`build/ntdll-unix/virtual_ios.c`, `process_ios.c`, `signal_arm64_ios.c`) под 36-битное адресное пространство A9 — перенос в окно **16–48 ГБ (`0x400000000` – `0xc00000000`)**, чтобы устранить падение `0xC0000005` (`addr=0x40000001`, не материализованный регион `0x40000000` из старого билда).
  3. Добавлены **36 стандартных видеорежимов** в `dxmt_display.cpp` (коммит `19c82fd`), чтобы устранить «мёртвую белую рамку без графики» в *Mark of the Ninja*.
  4. В `build/wine-pe/build-ntdll.sh` вшит патч авторасширения `NtCurrentTeb()->Tib.StackLimit` (до 256 КБ) в `call_seh_handlers` (`signal_x86_64.c`) для защиты фоновых потоков 32-битных игр.
  5. **Последний коммит в `main`:** `a39478a` (`Fix invalid None00 suffix in 48GB VA bounds constants`) — в очереди сборки GitHub Actions.
- **Следующие шаги по Madeira-A9:**
  1. Дождаться зелёного артефакта `.ipa` от коммита `a39478a` в GitHub Actions и установить через TrollStore на iPhone 6s.
  2. Протестировать запуск *Mark of the Ninja*, *Limbo* и *Braid*.
  3. Если какая-то из игр даст новый дамп `*.txt` — проанализировать адрес и стек сбоя (дампы сохраняются в Documents приложения).
  4. **Финальный полиш (после вывода графики в Mark of the Ninja):** поправить тач-ввод и клавиатурные скан-коды для *Knytt Stories* (сейчас удержание пальца по центру экрана замораживает цикл отрисовки MMF2 как `WM_NCLBUTTONDOWN`, а нижние игровые кнопки не передают скан-коды клавиатуры).

## 3. ПРОЕКТ №2: ARMSX2 (`~/Desktop/ARMSX2-master`, репо `TimRol83/ARMSX2`)
- **Цель:** Собрать рабочий порт PCSX2 на iOS 15 под чип Apple A9 для комфортной игры в ***Rule of Rose*** (в эмуляторе *Play!* она идёт в 10–13 FPS / 32 f/s при 162 dc/f в замедлении).
- **Что уже сделано:**
  1. Прописана оптимизация под CPU: `-mcpu=apple-a9+crc` для C/C++ в `platforms/ios/CMakeLists.txt`.
  2. Решена проблема падения `SwiftDriver ARMSX2iOS` (`unknown argument: '-pipe'`) — флаги `-pipe`, `-fvisibility=hidden`, `-pthread` изолированы только для `C,CXX` через генераторное выражение в кавычках `"$<$<COMPILE_LANGUAGE:C,CXX>:-pipe;-fvisibility=hidden;-pthread>"` в `cmake/BuildParameters.cmake` и `platforms/ios/cmake/BuildParameters.cmake`, очищен `XCODE_ATTRIBUTE_OTHER_SWIFT_FLAGS`.
  3. **Последний коммит в `main`:** `f200746` (`Quote generator expression in add_compile_options`) — в очереди/процессе сборки GitHub Actions.
- **Следующие шаги по ARMSX2:**
  1. Дождаться завершения сборки `.ipa` от коммита `f200746` в GitHub Actions. Если вылезет ошибка на этапе линковки или упаковки `.ipa` — разобрать лог и дать патч.
  2. Установить `.ipa` через TrollStore на iPhone 6s, загрузить BIOS и образ *Rule of Rose*.
  3. Подобрать оптимальные настройки под A9 (JIT включён, рендерер Metal, разрешение 1x Native, при необходимости EE Cycle Rate / Cycle Skip) для стабильной полной скорости.
